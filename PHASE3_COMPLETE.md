## 🎨 Design System

### Colors
```
Primary:   cyan-400/500    (IntelliSense, highlights)
Secondary: purple-400/500  (Refactoring, hints)
Info:      blue-400/500    (Information, CPU)
Success:   green-400/500   (Success, RAM)
Warning:   yellow-400/500  (Warnings)
Error:     red-400/500     (Errors)

Backgrounds: slate-900/800/700
Glass: rgba(30, 41, 59, 0.7) + blur(12px)
```

### Animations
```
Duration: 200-300ms (default)
Easing: ease-in-out
Types: slide, fade, shimmer, pulse, bounce
```

## 🚀 How to Test

1. **IntelliSense**: Press `Ctrl+Space` in the code editor
   - See glass morphism panel with icons
   - Hover over items to see selection effect
   - Notice smooth animation

2. **Hover Info**: Hover over keywords/variables
   - See tooltip with icon badge
   - Notice arrow pointer and smooth fade

3. **Context Menu**: Right-click in editor
   - See refactoring menu with glass effect
   - Hover over items for border indicator
   - Click "Optimize Performance"

4. **StatusBar**: Check bottom of IDE
   - See live CPU/RAM progress bars
   - Notice gradient backgrounds
   - Watch animated status dot

5. **Build Output**: Click "⚡ Build" button
   - See colorized build output
   - Notice SUCCESS/ERROR icons
   - Hover over lines for highlight effect

6. **Assembly View**: After building, click "ASM" tab
   - See header with line count
   - Notice enhanced syntax colors
   - Hover over lines for border effect

7. **Diagnostics**: Check "Axiom Analysis" tab
   - See summary badges (errors/warnings/hints)
